CC0 places no restrictions on use, modification, or redistribution, and

Modifications from the original:
  - Only the Color map is used. The pack's AmbientOcclusion, Displacement,
    NormalDX, NormalGL, and Roughness maps were discarded.
  - Re-encoded from JPEG to WebP at quality 82, which takes it from 1.41 MB
    to 291 KB. Resolution is unchanged at 1024x1024.

The normal and roughness maps the renderer uses are not shipped. They are
derived from this file at load time in src/art/textures.ts, which is what
keeps this directory to a single asset. See that file for the reasoning.
